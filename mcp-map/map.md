# 上海到台州五一 4 天旅行攻略开发记录

## 需求分析

用户需求:

1. 制作上海到台州 4 天的旅行攻略
2. 考虑出行时间、路线和天气状况
3. 制作网页地图,自定义绘制旅游路线和位置
4. 使用简约美观的页面风格,景区图片以卡片展示
5. 行程规划结果在高德地图 app 展示,并集成到 h5 页面
6. 同一天行程景区之间使用打车方式前往
7. 生成文件名为 kmTravel.html

## 开发过程

### 1. 初始调研

首先进行了以下调研:

- 搜索上海到台州的交通方式
- 查询台州旅游景点排名前十
- 查看五一假期台州天气预报
- 获取各个景点的地理位置坐标

### 2. 网页开发

创建了 kmTravel.html 文件,实现以下功能:

- 使用 Bootstrap 框架构建响应式布局
- 设计简约现代的 UI 界面
- 实现景点信息卡片展示
- 集成高德地图个性化地图功能
- 添加行程时间轴展示

### 3. 图片处理问题

遇到的问题:

1. 最初使用占位图片,无法显示
2. 尝试使用马蜂窝和携程图片链接,仍然无法显示
3. 最终使用高德地图 API 获取官方图片:
   - 通过 POI 搜索获取景点信息
   - 使用高德地图官方图片库的稳定链接
   - 成功显示所有景点和美食图片

### 4. 高德地图集成

实现的功能:

- 生成个性化地图链接
- 添加景点标记
- 规划旅游路线
- 提供扫码打开和链接打开两种方式

## 最终成果

完成了一个完整的旅游攻略网页:

1. 行程概览

   - 天气预报
   - 交通信息
   - 行程距离和时间

2. 详细行程安排

   - Day 1: 上海-天台山
   - Day 2: 神仙居一日游
   - Day 3: 长屿硐天-皤滩古镇
   - Day 4: 台州府城-返程

3. 特色内容

   - 景点详细介绍
   - 美食推荐
   - 出行建议
   - 注意事项

4. 技术特点
   - 响应式设计
   - 现代 UI 界面
   - 高德地图集成
   - 稳定的图片显示
